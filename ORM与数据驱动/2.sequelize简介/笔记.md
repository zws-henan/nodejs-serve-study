# sequelize简介

1. sequelize 是什么?
    - sequelize 是一个基于 Node.js 的 ORM，用于与 MySQL、PostgreSQL、MariaDB 等关系型数据库进行交互。
    - 它提供了一种简单而灵活的方式，将数据库表映射为 JavaScript 对象，从而简化了数据库操作。

## ORM

**ORM是什么**
    - ORM（Object-Relational Mapping）是一种将数据库表映射为对象的框架，它允许开发人员以对象的方式与数据库进行交互。
    - ORM 主要用于简化数据库操作，提高开发效率，减少重复代码的编写。
    - ORM 主要分为两种类型：关系型数据库 ORM 和非关系型数据库 ORM。
    - 关系型数据库 ORM 主要用于关系型数据库，如 MySQL、PostgreSQL、MariaDB 等。
    - 非关系型数据库 ORM 主要用于非关系型数据库，如 MongoDB、Redis 等。
