# mysql驱动程序

1. 什么是驱动程序？
    - 驱动程序是一种软件组件，用于在计算机和数据库之间进行通信。
    - 它负责将应用程序的请求转换为数据库可以理解的格式，然后将数据库的响应转换为应用程序可以理解的格式。
    - mysql驱动程序是连接内存数据和mysql数据库的桥梁。
        - mysql驱动程序通常使用：`mysql(官方)`, `mysql2(第三方:他的前身是mysql-native)`等。

## mysql2的使用

[官方文档](https://mysql2.nodejs.cn/)

1. 安装mysql2驱动程序
```bash
npm install mysql2
```

2. 引入mysql2驱动程序
```javascript
import mysql from 'mysql2/promise';
```

3. 创建数据库连接
```javascript
const connection = await mysql.createConnection({
  host: 'localhost',
  user: '',
  database: 'your_database_name',
  password: 'your_password',
});
```

4. 执行查询
```javascript
try {
  const [results, fields] = await connection.query(
    'SELECT * FROM `user`'
  );

  console.log(results); // results contains rows returned by server
  console.log(fields); // fields contains extra meta data about results, if available
} catch (err) {
  console.log(err);
}
```

### 语法细节

1. 关于参数化查询
    - 参数化查询是一种安全的查询方法，它将用户输入的参数与SQL语句分离，从而防止SQL注入攻击。
    - 参数化查询的语法是：`?`占位符，例如：`select * from `user` where `id` = ?`
    - 参数数组的顺序必须与SQL语句中的占位符顺序对应。
    - 参数数组可以包含多个参数，每个参数对应一个占位符。

2. execute方法
    - `execute` 方法是 mysql2 提供的**预编译查询**方法，与 `query` 方法类似，但有以下区别：
      - **预编译机制**：execute 会先将 SQL 语句发送到 MySQL 服务器进行预编译（prepare），然后再执行，适合多次执行相同 SQL 的场景
      - **参数转义**：自动对参数进行转义处理，彻底防止 SQL 注入攻击
      - **性能优化**：对于重复执行的 SQL，预编译后只需传输参数，减少网络开销
      - **返回值**：与 query 相同，返回 `[results, fields]` 数组
    - **语法示例**：
    ```javascript
    // 使用 execute 执行参数化查询
    const [results] = await connection.execute(
      'SELECT * FROM `user` WHERE `id` = ?',
      [1]  // 参数数组
    );
    console.log(results);
    
    // 插入数据示例
    const [insertResult] = await connection.execute(
      'INSERT INTO `company`(`name`, `location`) VALUES (?, ?)',
      ['测试公司', '上海']
    );
    console.log('插入的ID:', insertResult.insertId);
    ```
    - **query vs execute 的选择**：
      - 单次执行的简单查询：使用 `query` 即可
      - 需要执行多次的相同 SQL：使用 `execute` 性能更好
      - 需要最高安全性的场景：`execute` 更安全

3. query 与 execute 的区别详解
    - **执行机制的区别**：
      - `query`：将完整的 SQL 语句（包含参数值）直接发送给 MySQL 服务器执行
      - `execute`：先发送 SQL 模板到服务器进行预编译（prepare），然后只发送参数值执行
    - **性能对比**：
      - `query`：每次执行都需要解析和编译 SQL，适合单次或少量执行
      - `execute`：首次执行有预编译开销，但后续执行只需传输参数，适合多次执行相同 SQL
    - **安全性对比**：
      - `query`：参数化查询时也会转义，但内部实现是字符串替换后发送完整 SQL
      - `execute`：参数与 SQL 完全分离，由 MySQL 服务器处理参数绑定，安全性更高
    - **支持的 SQL 类型**：
      - `query`：支持任何 SQL，包括动态 SQL（如动态表名、动态列名）
      - `execute`：不支持动态 SQL，SQL 模板必须在预编译时确定
    - **详细对比表**：

      | 对比项 | query 方法 | execute 方法 |
      |--------|-----------|-------------|
      | **执行方式** | 直接发送完整 SQL | 预编译 + 参数执行 |
      | **首次执行性能** | 较快（无预编译开销） | 较慢（需预编译） |
      | **重复执行性能** | 每次都重新解析 | 复用预编译结果，更快 |
      | **安全性** | 较高（参数转义） | 最高（参数绑定） |
      | **动态 SQL** | 支持 | 不支持 |
      | **适用场景** | 单次查询、动态 SQL | 重复查询、批量操作 |

    - **何时使用 query**：
      ```javascript
      // 1. 单次执行的简单查询
      const [results] = await connection.query('SELECT * FROM `user`');
      
      // 2. 需要动态表名或列名的场景
      const tableName = 'user';
      const [results] = await connection.query(`SELECT * FROM \`${tableName}\``);
      ```

    - **何时使用 execute**：
      ```javascript
      // 1. 需要重复执行的查询（循环插入）
      const users = [{name: 'a'}, {name: 'b'}, {name: 'c'}];
      for (const user of users) {
        await connection.execute(
          'INSERT INTO `user`(`name`) VALUES (?)',
          [user.name]
        );
      }
      
      // 2. 高安全性要求的场景（用户输入）
      const username = req.body.username;
      const [results] = await connection.execute(
        'SELECT * FROM `user` WHERE `username` = ?',
        [username]
      );
      ```

4. pool对象（连接池）
    - **什么是连接池**：数据库连接池是一组预先创建并维护的数据库连接，供应用程序复用
    - **连接池的优势**：
      - **复用连接**：避免频繁创建和销毁连接的开销，提高性能
      - **控制并发**：限制最大连接数，防止数据库服务器过载
      - **自动管理**：连接池自动管理连接的创建、复用和释放
      - **高可用**：当某个连接失败时，自动创建新连接
    - **创建连接池**：
    ```javascript
    import mysql from 'mysql2/promise';
    
    // 创建连接池
    const pool = mysql.createPool({
      host: 'localhost',
      user: 'root',
      database: 'test',
      password: '123456',
      connectionLimit: 10,    // 最大连接数（默认10）
      waitForConnections: true,  // 连接数满时是否等待（默认true）
      queueLimit: 0,          // 等待队列最大长度（0表示无限制）
    });
    ```
    - **使用连接池的方式一：直接调用 execute/query**（推荐）：
    ```javascript
    // 直接从连接池获取连接执行查询，执行完自动释放
    const [results] = await pool.execute(
      'SELECT * FROM `user` WHERE `id` = ?',
      [1]
    );
    console.log(results);
    ```
    - **使用连接池的方式二：手动获取和释放连接**：
    ```javascript
    // 获取一个连接
    const connection = await pool.getConnection();
    
    try {
      // 使用连接执行查询
      const [results] = await connection.execute('SELECT * FROM `user`');
      console.log(results);
    } finally {
      // 释放连接回连接池
      connection.release();
    }
    ```
    - **关闭连接池**：
    ```javascript
    // 关闭连接池，释放所有资源
    await pool.end();
    ```
    - **连接池 vs 单连接**：
      - 单连接（`createConnection`）：适合简单的、低并发的应用场景
      - 连接池（`createPool`）：适合高并发、生产环境的应用，是推荐的方式
