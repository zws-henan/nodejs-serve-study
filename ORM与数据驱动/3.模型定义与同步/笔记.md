# 模型定义与同步

![ORM 原理图](./ORM原理图.jpg)

## 一、模型的定义

### 1.1 什么是模型

模型（Model）是 Sequelize 中的核心概念，它是数据库表的抽象表示。每个模型对应数据库中的一张表，模型的实例对应表中的一行数据。

### 1.2 模型定义的基本结构

模型定义包含三个部分：
- **模型名称**：首字母大写的单数形式，Sequelize 会自动转换为复数表名
- **属性（字段）定义**：定义表的列及其类型和约束
- **模型配置选项**：控制模型的行为（如时间戳、软删除等）

### 1.3 数据库连接配置

首先需要创建数据库连接实例：

```javascript
// models/db.js
import Sequelize from 'sequelize';

const sequelize = new Sequelize('myschooldb', 'root', '123456', {
    logging: null,           // 禁用 SQL 日志输出
    host: 'localhost',       // 数据库地址
    dialect: 'mysql',        // 数据库类型
});

export default sequelize;
```

**配置参数说明**：
- `database`：数据库名称
- `username`：数据库用户名
- `password`：数据库密码
- `host`：数据库服务器地址
- `dialect`：数据库类型（mysql/postgres/sqlite 等）
- `logging`：是否输出 SQL 语句（设为 null 可关闭）

### 1.4 模型定义示例

#### 示例 1：Student 模型

```javascript
// models/Student.js
import sequelize from "./db.js";
import { DataTypes } from "sequelize";

const Student = sequelize.define("Student", {
    // 学生姓名
    name: {
        type: DataTypes.STRING,   // 字符串类型
        allowNull: false,         // 不允许为空
    },
    // 出生日期
    birthDate: {
        type: DataTypes.DATE,     // 日期类型
        allowNull: false
    },
    // 性别（true为男，false为女）
    sex: {
        type: DataTypes.BOOLEAN,  // 布尔类型
        allowNull: false
    },
    // 手机号码（限制长度为11位）
    mobile: {
        type: DataTypes.STRING(11), // 指定长度的字符串
        allowNull: false
    }
}, {
    createdAt: false,   // 禁用自动创建时间字段
    updatedAt: false,   // 禁用自动更新时间字段
    paranoid: true      // 开启软删除
});

export default Student;
```

#### 示例 2：Class 模型（带关联）

```javascript
// models/Class.js
import sequelize from "./db.js";
import { DataTypes } from "sequelize";
import Student from "./Student.js";

const Class = sequelize.define("Class", {
    name: {
        type: DataTypes.STRING,
        allowNull: false,
    },
    openDate: {
        type: DataTypes.DATE,
        allowNull: false
    }
}, {
    createdAt: false,
    updatedAt: false,
    paranoid: true
});

// 定义关联：一个班级有多个学生（一对多）
Class.hasMany(Student);

export default Class;
```

#### 示例 3：Book 模型

```javascript
// models/Book.js
import sequelize from "./db.js";
import { DataTypes } from "sequelize";

const Book = sequelize.define("Book", {
    name: {
        type: DataTypes.STRING,
        allowNull: false,
    },
    imgUrl: {
        type: DataTypes.STRING,  // 图片URL（允许为空）
    },
    publicDate: {
        type: DataTypes.DATE,
        allowNull: false
    },
    author: {
        type: DataTypes.STRING,
        allowNull: false
    }
}, {
    paranoid: true  // 开启软删除
});

export default Book;
```

#### 示例 4：Admin 模型

```javascript
// models/admin.js
import sequelize from './db.js';
import { DataTypes } from 'sequelize';

const Admin = sequelize.define('Admin', {
    loginId: {
        type: DataTypes.STRING,
        allowNull: false
    },
    loginPwd: {
        type: DataTypes.STRING,
        allowNull: false
    },
    name: {
        type: DataTypes.STRING,
        allowNull: false
    }
}, {
    createdAt: false,
    updatedAt: false,
    paranoid: true

export default Admin;
```

## 二、核心知识点

### 2.1 DataTypes 数据类型

| 数据类型 | 说明 | 示例 |
|---------|------|------|
| `DataTypes.STRING` | 字符串（默认长度255） | `name: DataTypes.STRING` |
| `DataTypes.STRING(n)` | 指定长度的字符串 | `mobile: DataTypes.STRING(11)` |
| `DataTypes.DATE` | 日期时间类型 | `birthDate: DataTypes.DATE` |
| `DataTypes.BOOLEAN` | 布尔类型 | `sex: DataTypes.BOOLEAN` |
| `DataTypes.INTEGER` | 整数类型 | `age: DataTypes.INTEGER` |
| `DataTypes.TEXT` | 长文本类型 | `content: DataTypes.TEXT` |

### 2.2 字段属性

| 属性 | 说明 | 默认值 |
|------|------|--------|
| `allowNull` | 是否允许为空 | `true` |
| `unique` | 是否唯一 | `false` |
| `primaryKey` | 是否为主键 | `false` |
| `autoIncrement` | 是否自增 | `false` |
| `defaultValue` | 默认值 | `undefined` |

### 2.3 模型配置选项

| 选项 | 说明 | 默认值 |
|------|------|--------|
| `createdAt` | 是否自动添加 `createdAt` 字段 | `true` |
| `updatedAt` | 是否自动添加 `updatedAt` 字段 | `true` |
| `paranoid` | 是否开启软删除（添加 `deletedAt` 字段） | `false` |
| `timestamps` | 是否启用时间戳（同时控制 createdAt 和 updatedAt） | `true` |
| `tableName` | 指定表名（默认复数形式） | 模型名复数 |

### 2.4 关联关系

代码中使用了 `Class.hasMany(Student)` 定义一对多关系：

```javascript
// 一个班级有多个学生
Class.hasMany(Student);
```

常见的关联类型：
- `hasMany`：一对多（一个 Class 对应多个 Student）
- `belongsTo`：多对一（多个 Student 属于一个 Class）
- `hasOne`：一对一
- `belongsToMany`：多对多

### 2.5 软删除（paranoid）

开启 `paranoid: true` 后：
- 删除记录时不会真正删除，而是设置 `deletedAt` 字段
- 查询时会自动过滤已删除的记录
- 需要真正删除时使用 `destroy({ force: true })`

## 三、模型同步

### 3.1 同步方式

```javascript
// models/sync.js
import './admin.js'
import './Class.js'
import './Student.js'
import './Book.js'
import sequelize from './db.js'

// 同步所有模型
try {
    await sequelize.sync({
        alter: true  // 根据模型定义自动修改表结构
    });
    console.log('All models have been synchronized successfully.');
} catch (error) {
    console.error('Unable to sync the database:', error);
}
```

### 3.2 sync 方法的选项

| 选项 | 说明 |
|------|------|
| `{}` 或 `{ force: false }` | 只创建不存在的表 |
| `{ force: true }` | 删除并重新创建所有表（危险！） |
| `{ alter: true }` | 根据模型定义自动修改表结构（推荐） |

### 3.3 单个模型同步

```javascript
// 同步单个模型
await Student.sync({ alter: true });

// 同步所有模型
await sequelize.sync({ alter: true });
```

## 四、完整使用流程

```
1. 创建数据库连接 (db.js)
        ↓
2. 定义模型 (Student.js, Class.js, Book.js, Admin.js)
        ↓
3. 建立关联关系 (Class.hasMany(Student))
        ↓
4. 同步模型到数据库 (sync.js)
        ↓
5. 使用模型进行 CRUD 操作
```

### 入口文件

```javascript
// index.js
import './models/sync.js'
```

## 五、关键注意事项

1. **模型文件需要先引入**：同步前必须先导入所有模型文件
2. **关联定义位置**：通常在定义完两个模型后再定义关联
3. **软删除慎用**：开启后查询会自动过滤已删除记录，需要特殊查询时使用 `{ paranoid: false }`
4. **alter 选项的使用**：开发环境可用，生产环境建议手动写迁移脚本
5. **表名自动转换**：模型名 `Student` → 表名 `students`（复数形式）
