# mysql 笔记

## 库与表

### SQL 语句

sql是结构化查询语言，用于操作数据库。mysql是一个关系型数据库管理系统。且大部分的关系型数据有着基本一致的sql语法

分支：

1. DDL(Data Definition Language: 数据库定义语言) 语句
    - 操作数据库对象
        - 数据库
        - 数据表
        - 视图
        - 存储过程
        - 触发器

2. DML(Data Manipulation Language: 数据操作语言) 语句
    - 操作数据库中的数据
        - 数据插入语句
        - 数据查询语句
        - 数据更新语句
        - 数据删除语句
3. DCL(Data Control Language: 数据库控制语言) 语句
    - 数据库授权语句
    - 数据库回滚语句
    - 数据库提交语句
    - 数据库事务语句


### 管理库

> 创建数据库
```sql
-- 创建数据库
-- if not exists: 如果数据库不存在才创建。这个是可选的
-- database_name: 数据库名称
create database if not exists database_name;
```
> 删除数据库
```sql
-- 删除数据库
-- database_name: 数据库名称
drop database if exists database_name;
```

### 管理表

- 创建表
```sql
-- 创建表
-- if not exists: 如果表不存在才创建。这个是可选的
-- table_name: 表名称
-- NOT NULL: 不能为空值
-- column_name: 列名称
-- data_type: 数据类型
-- 数据类型(常用)：
    -- bit: 占一位，只能存储0或1，false或true
    -- int: 占32位，整数，有符号
    -- decimal(M,N): 可以精确计算的实数，M是总位数，N是小数位数
    -- varchar(M): 可变长度字符串，M是最大长度
    -- char(M): 固定长度字符串，M是固定长度
    -- date: 日期，格式为YYYY-MM-DD
    -- datetime: 日期时间，格式为YYYY-MM-DD HH:MM:SS
    -- text: 多行文本，最大65535个字符节
    -- blob: 二进制大对象
    -- enum(M): 枚举，只能取M个值中的一个
    -- set(M): 集合，可以取M个值中的任意个
    -- json: JSON格式的字符串
    -- xml: XML格式的字符串
-- primary key: 主键
-- auto_increment: 自动递增
-- default: 默认值
create table if not exists table_name (
    column_name data_type primary key auto_increment default value,
    column_name2 data_type NOT NULL default value2,
);
```
- 修改表
    - 修改表结构
    ```sql
    -- 修改表结构：添加列
    -- table_name: 表名称
    -- column_name: 列名称
    -- data_type: 数据类型
    -- NOT NULL: 不能为空值
    -- default: 默认值
    -- comment: 注释
    alter table table_name
    add column column_name data_type NOT NULL default value comment '注释';
    -- 修改表结构：删除列
    -- table_name: 表名称
    -- column_name: 列名称
    alter table table_name
    drop column column_name;
    -- 修改表结构：修改列
    -- table_name: 表名称
    -- column_name: 列名称
    -- data_type: 数据类型
    -- NOT NULL: 不能为空值
    -- default: 默认值
    -- comment: 注释
    alter table table_name
    modify column column_name data_type NOT NULL default value comment '注释';
    -- 修改表结构：修改主键
    -- table_name: 表名称
    -- column_name: 列名称
    -- primary key: 主键
    -- auto_increment: 自动递增
    -- default: 默认值
    alter table table_name
    modify column column_name data_type NOT NULL default value primary key auto_increment;
    -- 修改表结构：修改索引
    -- table_name: 表名称
    -- index_name: 索引名称
    -- column_name: 列名称
    -- unique: 唯一索引
    -- not unique: 非唯一索引
    alter table table_name
    modify index index_name column_name unique;
    -- 修改字段顺序
    -- table_name: 表名称
    -- column_name: 列名称
    -- after: 后跟的列名称表示将列插入到指定列的后面。也可以使用FIRST表示放在第一个位置。
    alter table table_name
    modify column column_name data_type NOT NULL default value after column_name2;
    ```

### 主键和外键

- 主键：
    - 主键是表中唯一标识每一行的列
    - 主键可以是单列也可以是多列
    - 主键不能为空值
    - 主键可以是自动递增的
    - 主键不可以有业务逻辑
- 外键：
    - 外键是表中引用其他表的列
    - 外键可以是单列也可以是多列
    - 外键不能为空值
    - 外键可以是自动递增的
    - 外键可以有业务逻辑

### 表关系

1. 一对一
    - 一个A对应一个B，一个B对应一个A
    - 例如：用户和用户信息表
    - 把任意一张表的主键同时作为外键，就可以实现一对一的关系
2. 一对多
    - 一个A对应多个B，一个B对应一个A
    - 例如：班级和学生表.用户和文章表
    - 在多一端的表上设置外键，对应到另一张表的主键或唯一索引列
3. 多对多
    - 一个A对应多个B，一个B对应多个A
    - 例如：学生和老师。商品和购物车表
    - 需要新建一个关系表(中间表),关系表至少要包含两个外键，分别对应到两张表的主键

### 三大设计范式

1. 要求数据库表的每一列都是不可分割的原子数据项

2. 非主键列必须依赖于主键列，不能依赖于其他非主键列

3. 非主键列必须直接依赖于主键列


### 表记录的增删改查(crud)

1. 插入记录
    - 语法：insert into table_name (column_name1,column_name2,...) values (value1,value2,...);
    - 例如：insert into user (loginid,password) values ('admin','123456');
    - 说明：
        - 插入记录时，必须提供主键列的值
        - 如果主键列是自动递增的，可以不提供主键列的值
        - 如果主键列是手动递增的，必须提供主键列的值
        - 如果主键列是唯一索引列，必须提供主键列的值
        - 如果主键列是索引列，可以不提供主键列的值
```sql
-- 插入记录:单列
-- table_name: 表名称
-- column_name1,column_name2,...: 列名称
-- value1,value2,...: 值
insert into table_name (column_name1,column_name2,...) values (value1,value2,...);

-- 插入记录:多列

insert into table_name (column_name1,column_name2,...) values (value1,value2,...)
(value1,value2,...);
(value1,value2,...);
```

2. 修改记录
    - 语法：update table_name set column_name1=value1,column_name2=value2,... where column_name=value;
    - 例如：update user set password='123456' where loginid='admin';
    - 说明：
        - 修改记录时，必须提供主键列的值
```sql
-- 修改记录
-- table_name: 表名称
-- column_name1,column_name2,...: 列名称
-- value1,value2,...: 值
-- column_name: 列名称
-- value: 值
update table_name set column_name1=value1,column_name2=value2,... where column_name=value;
```


## 查询

### 单表查询

从物理表（在硬盘上）中查询记录，生成结果表（在内存中）并显示出来

1. select和from 语句
    - 语法：select column_name1,column_name2,... from table_name
    - 别名：
        - 语法：column_name AS alias_name
        - 别名是查询结果中列的临时名称
        - 别名可以是单列也可以是多列
    - case when 语句：
        - 语法：case column_name when value1 then result1 when value2 then result2 else result3 end
        - 例如：select case when ismale = 1 then '男' else '女' end AS '性别' from employee;
        - 说明：
            - case when 语句可以实现多分支的判断

2. where 语句
    - 语法：where column_name = value
    - 例如：select * from employee where ismale = 1;
    - 说明：
        - where 语句可以实现查询记录的筛选
        - where 语句可以使用多个列进行筛选
        - where 语句可以使用多个运算符进行筛选
        - where的逻辑运算符
            - =
            - !=
            - >
            - <
            - >=
            - <=
            - in：用于筛选多个值的记录
            - is null：用于筛选空值的记录
            - is not null：用于筛选非空值的记录
            - between：用于筛选在两个值之间的记录
            - not between：用于筛选不在两个值之间的记录
            - like：用于筛选包含指定字符串的记录
            - not like：用于筛选不包含指定字符串的记录
            - distinct：用于筛选不同的值.去重
3. order by 语句
    - 语法：order by column_name1, column_name2, ...
    - 例如：select * from employee order by salary desc;
    - asc：升序
    - desc：降序
    - 说明：
        - 运行在select之后，可以使用case when 语句派生出的列进行排序
        - order by 语句可以实现查询结果的排序
        - order by 语句可以使用多个列进行排序
        - order by 语句可以使用升序和降序进行排序
        - order by 语句可以使用多个排序字段

4. limit 语句
    - 语法：limit offset, count
    - 例如：select * from employee limit 0, 10;
    - 说明：
        - limit 语句可以实现查询结果的分页
        - limit 语句可以使用offset和count参数
        - offset参数：指定从第几条记录开始查询
        - count参数：指定查询的记录数

### 多表查询

从多个表中查询记录，生成结果表（在内存中）并显示出来


1. 全连接(full join),笛卡尔积
    - 语法：select column_name1,column_name2,... from table_name1,table_name2
    - 说明：
        - 全连接可以查询两张表中所有的记录
        - 全连接可以查询两张表中所有的记录，包括空值
2. 左连接(left join)
    - 语法：select column_name1,column_name2,... from table_name1 left join table_name2 on column_name1 = column_name2
    - 说明：
        - 左连接可以查询左表中所有的记录(以左表为主)
        - 左连接可以查询右表中所有的记录，包括空值
3. 右连接(right join)
    - 语法：select column_name1,column_name2,... from table_name1 right join table_name2 on column_name1 = column_name2
    - 说明：
        - 右连接可以查询右表中所有的记录(以右表为主)
        - 右连接可以查询左表中所有的记录，包括空值
4. 内连接(inner join)
    - 语法：select column_name1,column_name2,... from table_name1 inner join table_name2 on column_name1 = column_name2
    - 说明：
        - 内连接可以查询两张表中所有的记录
        - 内连接可以查询两张表中所有的记录，包括空值

> SQL 执行顺序（优先级从高到低）

#### 完整执行顺序

```sql
1. FROM        -- 确定查询的数据源表
2. JOIN        -- 执行表连接操作
3. ON          -- 连接条件过滤
4. WHERE       -- 行级过滤（在分组前）
5. GROUP BY    -- 对结果进行分组
6. AGGREGATE   -- 执行聚合函数（COUNT/SUM/AVG等）
7. HAVING      -- 组级过滤（在分组后）
8. SELECT      -- 选择要返回的列
9. DISTINCT    -- 去重
10. ORDER BY   -- 对结果排序
11. LIMIT / OFFSET -- 限制返回行数
```

#### 各阶段详细说明

1. **FROM**：加载FROM子句中指定的表，创建笛卡尔积
2. **JOIN + ON**：根据ON条件过滤笛卡尔积，生成连接结果集
3. **WHERE**：对连接后的行进行过滤，只保留满足条件的行
4. **GROUP BY**：将满足WHERE条件的行按照指定列分组
5. **AGGREGATE**：对每个分组执行聚合函数计算
6. **HAVING**：过滤聚合后的分组，只保留满足条件的组
7. **SELECT**：选择要返回的列（包括聚合列和非聚合列）
8. **DISTINCT**：去除重复的行
9. **ORDER BY**：按照指定列对结果集排序
10. **LIMIT**：限制返回的行数

#### 示例分析

```sql
SELECT 
    department, 
    COUNT(*) AS total,
    AVG(salary) AS avg_salary
FROM employees
JOIN departments ON employees.dept_id = departments.id
WHERE salary > 5000
GROUP BY department
HAVING COUNT(*) > 3
ORDER BY avg_salary DESC
LIMIT 10;
```

执行过程：
1. FROM + JOIN：连接employees和departments表
2. ON：过滤dept_id匹配的行
3. WHERE：筛选salary > 5000的员工
4. GROUP BY：按department分组
5. AGGREGATE：计算COUNT(*)和AVG(salary)
6. HAVING：只保留员工数>3的部门
7. SELECT：选择department、total、avg_salary列
8. ORDER BY：按avg_salary降序排列
9. LIMIT：返回前10条

#### 重要注意事项

- **WHERE不能使用聚合函数**：因为WHERE在GROUP BY之前执行，此时还没有聚合结果
- **HAVING可以使用聚合函数**：HAVING在GROUP BY之后执行，聚合结果已经产生
- **SELECT中可以使用别名**：但ORDER BY不能直接使用SELECT中的别名（MySQL除外）
- **GROUP BY必须包含非聚合列**：SELECT中的非聚合列必须出现在GROUP BY中（MySQL有特殊处理）
