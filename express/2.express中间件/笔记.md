# express中间件

1. 当express示例匹配到请求时，会交给第一个函数处理，如果第一个函数没有调用next()方法，那么后续的中间件就不会被调用。

```js
app.请求方法(路径,中间件函数1,中间件函数2,中间件函数3)
```

**中间件函数**

1. 如果后续没有了中间件，express发现如果响应没有结束，express会响应404 Not Found

2. 如果中间件发生了错误，不会停止服务器。相当于调用了next(new Error("错误信息"))。会寻找后续的错误处理中间件。如果没有找到，就会响应500 Internal Server Error

## 常用中间件
1. express.static()
    - 用于处理静态文件的中间件。
    - 可以指定静态文件的目录。
    - 可以指定静态文件的默认文件。
    - 可以指定是否重定向。
2. express.json()
    - 用于处理json格式的请求体。
    - 可以指定最大请求体大小。
    - 可以指定是否解析嵌套对象。
3. express.urlencoded()
    - 用于处理urlencoded的请求体。
    - 可以指定最大请求体大小。
    - 可以指定是否解析嵌套对象。
