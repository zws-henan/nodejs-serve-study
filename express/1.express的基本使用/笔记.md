## express的基本使用

创建express应用实例

1. 方式一借助http模块

```js
import express from "express"
import http from "http"

const app = express();// 创建一个express应用实例
// app实际上是一个用于请求处理的函数
const server = http.createServer(app);
const PORT = 9527
server.listen(PORT,()=>{
    console.log(`server is running at http://localhost:${PORT}`);
})
```

2. 方式二借助express模块
```js
import express from "express"

const app = express();// 创建一个express应用实例
// app实际上是一个用于请求处理的函数
const server = app.listen(PORT,()=>{
    console.log(`server is running at http://localhost:${PORT}`);
})
```

## express的请求处理函数
- get()
- post()
- put()
- delete()
- all()
- use()

```js
app.get("/abc",(req,res)=>{
    // req和res是被express封装后的对象
    // ===获取请求信息===
    console.log("请求头:", req.headers); // 得到请求头信息
    console.log("请求方法:", req.method); // 得到请求方法 
    console.log("请求路径:", req.path); // 得到请求路径
    console.log("请求参数:", req.query); // 得到请求参数

    // ===响应客户端===
    // res.send("<h1>hello express</h1>");
    // res.json({name:"kuocheng"});

    // res.status(302).header("Location","https://www.baidu.com").end();
    // 上下的效果是一样的
    // res.status(302).location("https://www.baidu.com").end();
    res.redirect("https://www.baidu.com",302);
})
// 动态路由
app.get("/news/:id",(req,res)=>{
    console.log("请求路径:", req.path); // 得到请求路径
    console.log("请求参数:", req.query);
    console.log("动态路由参数:", req.params.id);
})
app.get("*path",(req,res)=>{ // * 表示匹配所有路径
    res.send("404 Not Found");
})
app.all("/news",(req,res)=>{ // all() 表示匹配该路径所有请求方法
    res.send("news");
})
```

## REST风格的API设计

这个概念是指在设计API时，使用HTTP方法来表示资源的操作，使用URL路径表示资源的位置。

例如：

- api/student
    - get: 获取所有学生
        - /api/student/:id : 获取指定学生的详情
        - /api/student/ ：获取所有学生的列表
        - /api/student?page=1&pageSize=10 ：获取第一页页10条学生列表
    - post: 创建学生
    - put: 修改学生
        - /api/student/:id
    - delete: 删除学生
