## 操作文件

需要使用到fs模块

1. 引入fs模块
```js
const fs = require('fs');
//或
import fs from 'fs';
```

2. 使用fs模块的方法操作文件
    - readFile(path,options,callback)
        - 读取文件
        - path:文件路径
        - options:配置对象或编码方式
            - encoding:编码方式
        - callback:回调函数
            - err:错误对象
            - data:读取到的数据
    - writeFile(path,data,options,callback)
        - 写入文件
        - 注意:写入文件时,如果文件不存在,会自动创建文件
        - path:文件路径
        - data:要写入的数据
        - options:配置对象
            - encoding:编码方式
            - flag:文件标志
                - w:写入(默认)
                - a:追加
        - callback:回调函数
            - err:错误对象
    - mkdir(path,options,callback)
        - 创建目录
        - options.recursive:是否递归创建父目录(默认false)
    - rmdir(path,options,callback)
        - 删除目录
        - 注意:删除目录时,如果目录不为空,会报错
        - options.recursive:是否递归删除目录(默认false)
    - stat(path,callback)
        - 获取文件或目录的信息
        - 返回fs.Stats对象
            - stats.isFile():是否是文件
            - stats.isDirectory():是否是目录
            - stats.size:文件大小(字节)
            - stats.mtime:最后修改时间
    - readdir(path,options,callback)
        - 读取目录下的所有文件或目录
        - options.withFileTypes:是否返回fs.Dirent对象(默认false)
    - access(path,mode,callback)
        - 检查文件或目录是否存在及权限
        - mode:检查模式
            - fs.constants.F_OK:文件是否存在
            - fs.constants.R_OK:是否可读
            - fs.constants.W_OK:是否可写

> fs的大部分方法都是异步的。除了有Sync后缀的是同步的等方法。

> 关于相对路径，除了导入导出模块里写相对路径是相对于当前文件的目录，其他地方写相对路径是相对于当前命令提示符的目录
