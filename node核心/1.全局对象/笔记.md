# node的全局对象

## 需要了解的几个全局对象
- globalThis
    - 全局对象，所有全局变量和函数都挂载在这个对象上
- setImmediate
    - 立即执行函数，用于在当前事件循环结束时执行指定的回调
    - 语法：setImmediate(callback, ...args).与setTimeout不同的是，setImmediate在当前事件循环结束时执行，而不是在指定的时间间隔后执行
- clearInterval
    - 清除定时器，用于清除setInterval创建的定时器
    - 语法：clearInterval(timerId)
- setTimeout
    - 定时器函数，用于在指定的时间间隔后执行指定的回调
    - 语法：setTimeout(callback, delay, ...args)
    - 注意：delay是毫秒级的时间间隔，不是秒级的时间间隔
- __dirname
    - 当前模块所在目录的路径
    - 它不在globalThis对象上，而是模块作用域变量
    - 语法：__dirname
- __filename
    - 当前模块的文件路径
    - 它不在globalThis对象上，而是模块作用域变量
    - 语法：__filename
- process
    - 进程对象，包含了当前进程的所有信息和方法
    - 语法：process
    - 有许多属性和方法，用于获取当前进程的信息和控制进程的行为
    - 例如：process.env、process.argv、process.exit()等
    - process.cwd()方法可以获取当前进程的工作目录
    - process.chdir()方法可以改变当前进程的工作目录
    - process.exit(code)方法可以退出当前进程
        - code:退出码(默认0表示成功)
    - process.argv数组包含了命令行参数
        - 第一个元素是node可执行文件的路径
        - 第二个元素是当前模块的文件路径
        - 后续元素是其他命令行参数
        - 例如：node index.js 123 456
        - process.argv数组包含了['node', 'index.js', '123', '456']
    - process.platform属性包含了当前进程的平台信息，例如：'win32'、'linux'、'darwin'等
    - process.env对象包含了环境变量，例如：'PATH'、'NODE_ENV'等
    - process.on()方法可以监听进程的事件，例如：'exit'、'SIGINT'等
        - 'exit':进程退出时触发
        - 'SIGINT':收到中断信号时触发(如Ctrl+C)
        - 'SIGTERM':收到终止信号时触发
        - 'uncaughtException':未捕获异常时触发
    - process.kill(pid, signal)方法可以向指定的进程发送信号
- Buffer
    - 缓冲区对象，用于处理二进制数据
    - 继承自Uint8Array对象.用法基本相同
    - 语法：Buffer.from()
    - 语法：Buffer.alloc(size)
    - 语法：Buffer.allocUnsafe(size)
- require
    - 引入模块的函数，用于在当前模块中引入其他模块
    - 语法：require(moduleName)
    - 注意：ESM模块中使用import
- module
    - 当前模块对象，包含了当前模块的所有信息和方法
    - 语法：module
    - 注意：ESM模块中没有module对象
