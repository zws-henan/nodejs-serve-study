# node的内置模块

1. os
    - os:[os文档地址](https://node.org.cn/docs/latest/api/os.html)
    - EOL
        - 表示一行结束的分隔符
    - arch()
        - 获取cpu的架构名。基本上是x32或x64
    - cpus()
        - 获取cpu每一个核的信息。每一个信息是一个对象
    - freemem()
        - 获取当前空闲的内存。单位是字节
    - homedir()
        - 返回用户目录
    - hostname()
        - 获取主机名
    - tmpdir()
        - 返回操作系统的临时目录
2. path
    - path:[path文档地址](https://node.org.cn/docs/latest/api/path.html)
    - basename(path,ext)
        - 获取路径的文件名
        - ext是可选的,如果提供了,会去掉文件名的扩展名
    - delimiter
        - 获取环境变量路径分隔符
        - Windows是';',Linux是':'
    - sep
        - 获取路径分隔符
        - Windows是'\\',Linux是'/'
    - dirname(path)
        - 获取路径的目录名
    - extname(path)
        - 获取路径的扩展名
    - normalize(path)
        - 规范化路径
    - relative(path1,path2)
        - 生成path2相对于path1的相对路径.
        - 注意它会认为路径里的所有元素都是文件夹
    - resolve(path1,path2)
        - 解析路径.根据当前命令行路径返回绝对路径
        - 注意它会认为路径里的所有元素都是文件夹
    - join()
        - 连接路径
    - parse()
        - 解析路径
    - format()
        - 格式化路径
3. url
    - url:[url文档地址](https://node.org.cn/docs/latest/api/url.html)
    - parse(url,parseQueryString)
        - 解析url
        - parseQueryString:是否解析查询字符串(默认false)
    - format(urlObject)
        - 格式化url
        - 将url对象转换为字符串
4. util
    - util:[util文档地址](https://node.org.cn/docs/latest/api/util.html)
    - callbackify(fn)
        - 将异步函数转换为回调函数
    - inspect(object,options)
        - 检查对象
        - 返回对象的字符串表示
    - isBuffer(object)
        - 检查对象是否是Buffer
    - isArray(object)
        - 检查对象是否是Array
    - isString(object)
        - 检查对象是否是String
    - isNumber(object)
        - 检查对象是否是Number
    - isBoolean(object)
        - 检查对象是否是Boolean
